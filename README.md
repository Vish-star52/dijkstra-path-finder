# Dijkstra Path Finder

A Python desktop app that visualizes the shortest path between cities using Dijkstra's algorithm.

## Features
- Network graph visualization
- Weighted city-to-city distances
- Interactive start and target selection
- Highlighted shortest path

## Run locally

```bash
pip install -r requirements.txt
python "DAAproject.py"
```

## Project files
- `DAAproject.py` — main app

## Requirements
- Python 3.9+
- tkinter
- networkx
- matplotlib
- numpy
